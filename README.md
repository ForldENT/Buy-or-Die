# BUY OR DIE — 사거나, 죽거나

> 1,000만 원으로 시작하는 초고속 주식·코인 투자 생존 게임 (Unity 6 · 2D)

내 PC 화면을 그대로 보는 시점의 트레이딩 게임입니다. 바탕화면 위에 HTS 창과 작업표시줄이 떠 있고, 시간은 현실보다 훨씬 빠르게 흐릅니다. 뉴스를 읽고 남들보다 먼저 사고팔아 **총자산 10억(BUY)** 을 만들면 승리, **1만 원 아래(DIE)** 로 떨어지면 파산입니다.

---

## 주요 기능

| 구분 | 내용 |
|---|---|
| 종목 | 국내 주식 50 · 해외 주식 50 · 코인 100 (실존 종목 패러디 이름) |
| 거래 | 현물 매수/매도, 레버리지 롱/숏 (주식 최대 x10, 코인 최대 x50), 강제 청산 |
| 시간 | 게임 1분 = 현실 0.25초 (장중 기준), 일시정지 / 1x / 2x / 5x |
| 장 시간 | 국내 평일 09:00~15:30 · 해외 평일 22:30~05:00(한국 시간) · 코인 24시간 · 주말 주식 휴장 |
| 뉴스 | 300종 중 하루 10개 무작위 발표, 기업 악재는 몇 시간 안에 반드시 하락 / 호재는 반드시 상승 |
| 상장폐지 | 관리종목 지정 → 정리매매 → 상장폐지 (현물 0원, 포지션은 마지막 가격으로 정산) |
| 진행 | 새 게임(튜토리얼) / 이어하기, 매일 자정 자동 저장 |
| 기타 | 투자자 등급(깡통 계좌 → 월가의 늑대), 일일 손익 리포트, 최고 기록 저장, 효과음 |

## 실행 방법

1. **Unity 6 (6000.3.x)** 로 프로젝트를 엽니다.
2. `Assets/Scenes/Title.unity` 를 열고 ▶ 재생합니다.
3. 빌드 순서: `Title` (0) → `MainGame` (1)

> `MainGame` 씬을 바로 재생해도 됩니다. 이 경우 새 게임 + 튜토리얼로 시작합니다.

### 빌드
- **Windows**: File → Build Profiles → Windows → Build
- **WebGL**: Build Profiles에서 WebGL로 전환 후 Build
  - 입력은 Input System, 저장은 PlayerPrefs, 효과음은 코드로 합성하므로 WebGL에서도 그대로 동작합니다.

## 게임 방법

1. 왼쪽 관심종목에서 종목을 고릅니다 (국내 / 해외 / 코인 / 보유 탭, 정렬 가능).
2. 가운데 차트에서 흐름을 봅니다. 마우스를 올리면 시가·고가·저가·종가가 보입니다.
3. 오른쪽 주문창에서 거래합니다.
   - **현물**: 수량(10% · 25% · 50% · 최대, ± 미세 조정)을 고르고 매수/매도
   - **레버리지**: 배율과 증거금을 고르고 **롱(오르면 수익)** / **숏(내리면 수익)**
   - 청산가에 닿으면 증거금을 전부 잃습니다.
4. 오른쪽 아래 뉴스를 읽고 먼저 움직이세요.
5. 아래 표에서 보유 자산 · 포지션 · 거래 내역을 확인하고 정리합니다.

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `1` `2` `3` | 1x / 2x / 5x 배속 |
| `↑` `↓` | 종목 이동 |
| `Tab` | 국내 / 해외 / 코인 탭 전환 |
| `Esc` | 일시정지 메뉴 (계속 · 저장 · 설정 · 타이틀로) |
| 타이틀 `↑` `↓` `Enter` | 메뉴 선택 |

## 게임 규칙 상세

### 시장
- 가격 = 시장 흐름 + 섹터 흐름 + 뉴스 추세 + 적정가 회귀 + 무작위 변동
- 국내 주식은 상·하한가 ±30% (정리매매 중에는 제한 없음)
- 장이 닫혀 있는 동안 나온 뉴스는 다음 개장 때 **갭**으로 반영
- 코인 일일 기준가는 매일 09:00에 초기화
- 수수료 0.05% (현물·레버리지 공통)

### 뉴스 (300종)
| 종류 | 개수 | 영향 |
|---|---|---|
| 기업 호재 / 악재 | 70 / 70 | 해당 종목 ±5~14% |
| 코인 호재 / 악재 | 35 / 35 | 해당 코인 ±8~22% |
| 섹터 호재 / 악재 | 20 / 20 | 섹터 전체 ±3~8% |
| 거시경제 | 20 | 국내 / 해외 / 코인 시장별 방향 |
| 시사 | 30 | 영향 없음 |

뉴스가 나오면 1~4시간(장중 기준)에 걸쳐 목표가까지 가격이 끌려가도록 설계되어, 방향이 반드시 뉴스와 일치합니다.

### 상장폐지
1. **관리종목 / 유의 종목 지정** — 가격 하락, 경고 공시
2. 다음 거래일: 60% 확률로 **정리매매**(-55~80%), 40%는 지정 해제
3. 장 마감 후 **상장폐지** — 현물 보유분 0원, 레버리지 포지션은 마지막 가격으로 정산 (숏은 수익)

### 승패
- **BUY**: 총자산 10억 원 달성 (계속 플레이 가능)
- **DIE**: 열린 포지션 없이 총자산 1만 원 미만 → 저장 기록 삭제

## 프로젝트 구조

```
Assets/
├─ Scenes/
│  ├─ Title.unity          # 타이틀 (시작 화면)
│  └─ MainGame.unity       # 메인 게임
├─ Resources/Fonts/        # 나눔고딕 (OFL)
└─ Scripts/
   ├─ GameManager.cs       # 진행 총괄: 시작 방식, 배속, 저장, 승패, 알림
   ├─ Sfx.cs               # 코드로 합성하는 효과음
   ├─ Core/
   │  ├─ MarketData.cs     # 종목 / 캔들 / 뉴스 데이터 구조
   │  ├─ AssetCatalog.cs   # 종목 200개 목록
   │  ├─ NewsCatalog.cs    # 뉴스 300종
   │  ├─ MarketEngine.cs   # 시장 시뮬레이터 (달력, 장 시간, 뉴스 일정, 상장폐지)
   │  ├─ Portfolio.cs      # 계좌 (현금, 현물, 포지션, 거래 기록)
   │  └─ SaveSystem.cs     # 저장/불러오기, 설정, 시작 방식
   └─ UI/
      ├─ UIKit.cs          # 테마 색, 숫자 포맷, UI 생성 헬퍼, 버튼
      ├─ UIExtras.cs       # 바탕화면, 모달, 설정 창
      ├─ GameUI.cs         # 메인 화면 조립 (HTS 창, 작업표시줄, 알림, 메뉴)
      ├─ ChartView.cs      # 캔들 차트
      ├─ WatchlistView.cs  # 관심종목 (가상 스크롤)
      ├─ OrderView.cs      # 주문창
      ├─ PortfolioView.cs  # 보유 / 포지션 / 거래 내역 표
      ├─ NewsView.cs       # 뉴스 피드
      ├─ TutorialOverlay.cs# 새 게임 튜토리얼
      ├─ TitleUI.cs        # 타이틀 화면
      └─ SceneFader.cs     # 씬 전환 페이드
```

> 씬에는 카메라, EventSystem, 관리 오브젝트(GameManager / Title)만 있고 UI는 실행 시 코드로 조립됩니다.

## 조정 포인트

| 항목 | 위치 |
|---|---|
| 게임 속도 (장중 / 장 마감 / 주말) | `GameManager` 인스펙터 `secondsPerMinuteOpen` · `Closed` · `Weekend` |
| 시작 자금, 수수료, 유지 증거금 | `Portfolio.cs` `StartCash` · `FeeRate` · `MaintRate` |
| 승리 / 파산 기준 | `GameManager.cs` `GoalEquity` · `DieEquity` |
| 하루 뉴스 개수 | `MarketEngine.cs` `NewsPerDay` |
| 종목 추가·수정 | `AssetCatalog.cs` — `이름\|티커\|섹터\|시작가\|1분 변동성\|시장 민감도` |
| 뉴스 추가·수정 | `NewsCatalog.cs` — `{0}` 자리에 종목 이름이 들어감 |
| 색상 | `UIKit.cs` `Theme` |

## 저장 데이터

- PlayerPrefs 키 `bod_save_v2` 에 JSON으로 저장됩니다.
- 최고 기록: `bod_best_equity`, `bod_best_day`
- 설정: `set_volume`, `set_greenup`, `set_speed`, `set_autosave`, `set_alerts`
- 타이틀 → 설정 → **저장 데이터 삭제** 로 초기화할 수 있습니다.
